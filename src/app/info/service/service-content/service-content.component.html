Service level for Uganda Christian University Digital Institutional Repository

This page describes the service level expectations for the Uganda Christian University Digital Institutional Repository, the institutional repository service for preserving and sharing UCU research outputs and approved digital materials.

Repository purpose and scope

The repository supports Uganda Christian University's commitment to collect, preserve, describe, disseminate, and provide long-term access to its research, scholarship, theses, dissertations, datasets, publications, and institutional digital outputs.

The repository is built on DSpace, a widely used open source repository platform. It provides search and browse facilities, item pages, metadata records, file access controls, persistent links, usage statistics, repository administration, and harvesting support for discovery and indexing.

Depositor services

Depositors and authorised repository staff may:

  • submit research outputs and approved institutional materials for review and publication;
  • provide metadata, files, rights statements, embargo details, and licensing information;
  • request corrections, updates, new versions, new communities, or new collections;
  • request temporary access restrictions where justified by copyright, confidentiality, ethics, legal, funder, or institutional requirements;
  • use repository citations, handles, DOIs where available, or other persistent links when citing deposited items;
  • attach an open licence or clear rights statement to repository content.

Depositors are responsible for supplying accurate metadata, appropriate file formats, and evidence that they have permission to deposit the material.

Availability and support

The repository is intended to be available online on a continuous basis, except during planned maintenance, service upgrades, network interruptions, hosting incidents, or emergency technical work.

Routine maintenance should be announced in advance where practical. Repository support is provided during normal Uganda Christian University working hours through the library and repository support workflow.

Resilience, backup, and recovery

The repository service should be managed with appropriate safeguards for system reliability, metadata quality, digital file protection, and recovery from technical incidents. These safeguards may include controlled administrative access, regular backups, repository monitoring, secure storage, and preservation workflows.

In the event of an incident affecting service availability or data integrity, repository administrators will work to restore access from available backups or replicated service components according to institutional technical procedures.
